# HOT 한 줄 위젯 변경 검토

범위: R10/R11, src/widget/ranking.ts와 ranking.css, 브라우저 회귀 테스트. 기준 커밋 0de8503. 새 문맥 리뷰어 hot_ticker_review에게 변경 diff와 명세를 제공했다. 전체 EGM loop 완료를 뜻하지 않는다.

- 자동 갱신 시 요약 링크에서 패널 내부 링크로 포커스가 이동할 수 있는 문제를 구현자와 검토자가 각각 확인했다. .post-link에서 시작한 포커스만 복원하도록 수정했다. 새 회귀 테스트의 실패 후 통과를 확인했다.
- 제거 후 재연결 시 오래된 hover 상태를 남기지 않도록 초기화했다.
- 검토자는 위 수정 후 추가 차단 지적이 없다고 반환했다. 순환 정지 조건, 현재 글 유지, 링크 검증, Escape/외부 클릭 닫기, 좁은 화면 CSS가 명세와 일치함을 검토했다.
- 경미 지적: 초기 오류의 재시도 버튼은 같은 줄이 아니라 아래에 있다. 320px에서 충돌하지 않는 배치를 유지하고 설계 설명을 실제 동작에 맞췄다.

검증: pnpm typecheck 통과. API/카탈로그 19개와 브라우저 17개 통과. pnpm build dry-run 통과. Chromium 320/390/1440px의 접힘과 펼침 스크린샷을 확인했다. 실제 Safari 기기 검증과 티스토리 스킨 적용은 이 결과에 포함하지 않는다.

# 독립 코드 검토와 조치

검토자는 fork_turns=none의 새 대화 문맥에서 명세, 설계, 구현, 테스트, 설치/배포 문서를 읽었다. 검토 당시 baseline은 1c6cb8b이고 구현은 d200979 및 작업 트리를 포함했다. 전체 EGM 반복 검토 완료를 뜻하지 않는다.

검토자가 독립 실행한 검사는 `pnpm typecheck`와 `node --experimental-strip-types --test tests/catalog.test.ts`(당시 3개 통과)다. 브라우저 검사는 구현자가 수행한 것으로 구분했다.

## 중요 지적과 조치

| 지적 | 조치와 근거 |
| --- | --- |
| pnpm deploy는 패키지 export 예약 명령 | README를 pnpm run deploy로 수정. 실제 실행이 사용자 스크립트에 진입하고 development 설정에서 중단되는 것을 확인 |
| 원격 D1 import는 명시적 BEGIN/COMMIT 미지원 | 생성기와 seed에서 트랜잭션 표식을 제거. D1 remote import가 트랜잭션을 소유하도록 함. 생성 SQL의 따옴표 보존과 비활성화는 실제 D1 테스트로 확인. 운영 원격 import는 아직 실행하지 않음 |
| 실패한 글 10개가 갱신을 독점 | checked_at을 verified_at과 분리하는 0002 마이그레이션 추가. 10개가 실패해도 다음 패스에 정상 글이 검증되는 실패 테스트를 먼저 확인한 뒤 수정 |
| 공개 상태 확인과 기록의 경쟁 조건 | 상태 확인과 조건부 dedup INSERT를 같은 D1 batch에 포함. 비활성화된 글을 storage 경계에서 직접 거절하는 실패 테스트 후 수정 |
| 주석/스크립트/템플릿의 가짜 HTML을 공개 본문으로 오인 | htmlparser2로 실제 요소를 파싱. head 메타만 허용하고 inert 내용은 제외하며 모든 요소에서 보호 표식을 확인. 실패 테스트 후 수정 |
| 전체 응답을 읽은 뒤 크기 검사 | 스트림을 읽으면서 bytes 기준 제한. sitemap 256KiB, 글 HTML 2MiB. 다중 바이트 문자열이 한도를 넘으면 중단하는 실패 테스트 후 수정 |
| 실제 API 화면을 예시로 표시 | live 모드의 바깥 배너도 실제 API 결과로 바꿈. 브라우저 실패 테스트 후 수정 |
| 자동 갱신 시 링크 포커스 상실 | 접근성 요구사항에 영향을 주므로 minor에서 중요로 재분류. 같은 글이 남아 있으면 focus와 스크롤 위치 보존. 성공/실패 갱신의 포커스 테스트가 실패하는 것을 먼저 확인한 뒤 수정 |

## 남긴 경미한 항목

- 이미 숨겨진 탭에서 새 컴포넌트를 연결하면 최초 조회 한 번은 실행한다. 이후 타이머는 정지하며 표시될 때 갱신한다. 통계 정확도나 노출에 영향을 주지 않는 1회 읽기 비용이다.
- 사이드바 예시의 s_sidebar_element 바로 아래에 관리자 편집기용 이름 주석을 별도로 넣는 편집기 편의 개선은 미반영이다. 화면 출력에는 영향이 없다.

## 검토 밖 운영 검증

Cloudflare 실제 배포/비밀키/원격 D1, 인증된 티스토리 스킨 적용, Safari/iOS 실기기는 미검증이다. 기본 모바일웹 실행 범위와 Origin 인증 한계는 명세에 명시된 운영 경계다.

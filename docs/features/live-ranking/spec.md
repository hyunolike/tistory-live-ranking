# 실시간 인기글 위젯 명세

상태: 사용자가 저장소 생성과 개발 진행을 요청했다. 아래 세부 수치와 기술 선택은 구현자의 결정이며 독립 검토로 보완한다.

## 목적과 첫 가치

hyunolike tech 방문자가 지금 다른 독자들이 읽는 글을 찾아 원문으로 이동한다. 블로그 진입 → 기간 선택 → 인기글 링크 클릭이 핵심 흐름이다.

## 요구사항과 수용 기준

| ID | 요구사항 | 수용 기준 |
| --- | --- | --- |
| R1 | 별도 GitHub 저장소 | `hyunolike/tistory-live-ranking`, 공개, main과 재현 가능한 lockfile |
| R2 | 기간별 인기글 | 최근 1시간과 최근 24시간의 중복 제외 조회순 TOP 5. 기본 24시간. 동률은 글 ID 오름차순 |
| R3 | 조회 수집 | 공개 카탈로그에 등록된 글만 집계. 숫자형 글 ID와 모바일 /m/ID는 같은 글로 취급. 검색, 홈, 공지, 보호글 제외 |
| R4 | 중복과 입력 보호 | 서버 시각 기준 동일 IP의 동일 글을 30분 동안 한 번 집계. IP는 일 단위 HMAC 지문으로만 저장. 같은 IP 1분 30건 이후 429. 원본 IP 영구 저장 없음 |
| R5 | 기존 디자인 호환 | 사용자가 제공한 CSS의 #ef402f, #1a1a1a, #333, #777, #e8e8e8, 흰 배경, SF Mono 계열 메타, 시스템 한글 본문. 전역 CSS를 덮어쓰지 않음 |
| R6 | 정직한 상태 표시 | 로딩, 빈 목록, 장애, 이전 정상 결과 유지, 재시도 제공. 샘플은 '디자인 미리보기 / 예시 데이터'로 명시하고 수집하지 않음 |
| R7 | 갱신과 접근성 | 60초 갱신, 숨긴 탭에서는 중단. 버튼 키보드 조작, 보이는 포커스, 320px에서 가로 넘침 없음, 모션 줄이기 지원 |
| R8 | 설치와 운영 | 상단 독립 영역과 300px 사이드바 삽입 예제. 수집은 모든 공개 글, 표시는 원하는 위치. 코드 제거로 원복 가능 |
| R9 | 로컬 개발 | Cloudflare 계정 없이 로컬 D1 마이그레이션, 실 API 수집/랭킹 확인, 정적 위젯 빌드 가능 |
| R10 | HOT 한 줄 순환 | 접힌 상태는 HOT 배지, 순위, 한 줄 제목과 펼침 버튼. 제목은 원문 링크이며 긴 제목은 말줄임. 5초마다 순환하고 펼침/마우스 진입/키보드 포커스/숨긴 탭/모션 줄이기에서 자동 순환 중단. 명시적인 일시정지 버튼 제공 |
| R11 | 전체 순위 펼침 | 펼침 버튼으로 TOP 5, 기간 선택, 집계 기준과 갱신 시각 표시. Escape 또는 외부 클릭으로 닫기. Escape는 펼침 버튼으로 포커스 복귀. 빈 상태와 오류는 접힌 줄에서도 확인 가능 |

## 경계와 한계

- 집계 시작 이후의 데이터만 제공한다. 티스토리 통계와 동일한 수치를 보장하지 않는다.
- 30분 중복 제외 조회이며 실제 고유 방문자나 현재 동시 접속자 수가 아니다. 일 경계에서 HMAC 지문이 바뀌면 중복 기준도 초기화된다.
- 동일 공인 IP를 쓰는 독자는 합산 과정에서 누락될 수 있다. 공개 API의 고의적 조작과 자동 브라우저를 완전히 차단하지 않는다.
- 운영 D1 생성, Cloudflare 배포, 티스토리 스킨 실제 적용은 이 구현의 검증과 구분한다.
- 제목과 URL은 방문자 요청을 신뢰하지 않고 운영자가 동기화한 공개 글 카탈로그에서 가져온다.
- 순위 상승 표시, 로그인, 관리자 대시보드, WebSocket, 누적 과거 통계 이관은 범위 밖이다.

## 검증

- 서버: 실제 로컬 D1에서 잘못된 origin/body/글 ID, 등록되지 않은 글, 동시 중복, 30분 경계, 시간 범위와 동률, 요청 제한, 정리 작업을 확인한다.
- 브라우저: 실 API 결과, 기간 전환, 오류와 재시도, 빈 상태, XSS 문자열, 320/390/1440px, 포커스, 외부 스킨 CSS 충돌을 확인한다.
- 공개 블로그 메타데이터 동기화와 실제 운영 통계 수집을 구분한다. 데모 조회를 운영에 쓰지 않는다.


## 운영 요청 변경

2026-11-24 사용자가 모두투어와 하나투어의 실시간 인기 검색어 및 HOT 배지 이미지를 제시했다. 표현은 한 줄 순환 위젯으로 변경하며 데이터는 기존 인기글 조회수를 유지한다. 기본 빨간색은 기존 스킨을 따르고 CSS 토큰으로 보라색 등 변경 가능하다. 자동 순환은 표현이며 API 갱신은 기존 60초를 유지한다.

2026-11-24 사용자가 계속 진행과 공개 저장소 전환을 요청했다. R1의 공개 범위를 갱신했다. 운영 D1과 Worker 배포, 공개 HTTPS 검증 및 main 병합을 완료했고 실제 티스토리 스킨 적용은 Chrome 조작 확인을 기다린다.

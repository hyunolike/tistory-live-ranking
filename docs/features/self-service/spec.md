# 블로그 주소로 설치하는 공개 위젯

사용자 요청: 다른 사용자도 티스토리 주소를 입력해 이용하도록 확장한다. 실제 스킨 적용은 사용자가 직접 한다.

## 범위와 수용 기준

- S1: /start/에서 로그인 없이 https://이름.tistory.com 주소를 등록하고 전용 설치 코드를 받는다. 기존 주소를 다시 등록하면 같은 ID를 반환한다. 개인 도메인은 이번 범위에서 제외한다.
- S2: 등록 상태는 pending. 코드가 실제 블로그 홈의 실행 가능한 script 태그에 존재하는지 확인하고 공개 글 카탈로그를 확보한 뒤 active로 전환한다. 비밀번호를 받거나 스킨을 자동 수정하지 않는다.
- S3: 블로그별 글, 조회, 중복 제외, 집계 시작 시각을 분리한다. 같은 글 번호도 서로 다른 글이다. 다른 origin이나 비활성 블로그의 수집은 거절한다.
- S4: 기본 티스토리 공개 본문 마크업과 숫자형/문자형 글 주소를 지원한다. 보호/삭제 글과 외부 canonical은 제외한다. 링크와 제목은 검증한 카탈로그만 사용한다.
- S5: 기존 hyunolike 위젯, API, DB 통계와 배포 주소를 유지한다. 기존 테이블을 삭제하거나 이동하지 않는다.
- S6: 주소 검증은 정확한 tistory.com 하위 호스트와 HTTPS만 허용한다. 사용자 지정 포트/인증정보/경로/쿼리를 거절하고 외부 리디렉션을 따라가지 않는다. 등록/확인 요청은 제한하며 활성화 전 크롤링은 확인 요청에만 수행한다.
- S7: 설치 코드 복사, 설치 확인, pending/active/오류 안내를 제공한다. 320px에서 가로 넘침 없음. 코드 제거 시 해당 블로그 수집이 중단된다.

통계는 설치 이후 30분 중복 제외 조회다. 티스토리 기존 통계를 가져오지 않는다. site ID는 공개 식별자이며 비밀키나 관리자 권한이 아니다.
